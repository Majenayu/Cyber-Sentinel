# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow for this repository when it is available.
If it is unavailable, contact the repository maintainer privately through
GitHub with the affected path, reproduction steps, impact, and mitigation.

Never include tokens, credentials, personal data, or exploit payloads that
could affect a live system. Redact all sensitive values before submitting a
report.

## Scope

Reports should be reproducible against the current default branch or a
published deployment. This is a prototype security dashboard; treat its
automation and integration features as requiring human authorization and
independent review before production use.
